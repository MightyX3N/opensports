# Recorded sources for the bowling sounds

`tools/sfx/make_bowling.py` cuts and processes these into `assets/sounds/bowling/`.

| File | From | Licence |
|---|---|---|
| `juskiddink-strike2.wav`, `juskiddink-strike3.wav` | "Bowling Strike Hit" on OpenGameArt (https://opengameart.org/content/bowling-strike-hit): recordings by juskiddink (freesound.org sounds 82358, 82359), cut and normalised by qubodup | CC-BY-SA 3.0 (https://creativecommons.org/licenses/by-sa/3.0/) |
| `qubodup-bowling-roll.ogg` | "Bowling Ball Rolling" by qubodup on OpenGameArt (https://opengameart.org/content/bowling-ball-rolling) | CC0 |

The sounds made from the strike recordings (`crash_*`, `clack_*`, `ball_pin_*`, `pin_*`, the ambience) are adaptations and stay CC-BY-SA 3.0.
